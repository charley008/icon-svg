导入与导出

素材保存在挂载的 library 目录中，导入后立即生效，无需更新 Docker 镜像或重启。

↓ 导出完整素材库导出已上架素材

分类补全只更新空分类或“其他”，保留已经设置的具体分类。

支持本项目导出的 ZIP（含 meta.json、SVG 和许可文件），最大 64 MB。只追加缺失素材；重复内容或相同来源自动跳过，保留现有资料、默认图标和上下架状态。

正在校验并导入，请保持页面打开。大型素材库可能需要一些时间。

完整素材库包含未上架及回收站记录，不包含账号、密码或数据库。导入用于追加合并，不会覆盖或删除现有素材。

刷新状态

直接复制 SVG 到 library 后，点击扫描即可登记。新的产品需先在 meta.json 中声明。扫描失败时不会发布错误素材。
